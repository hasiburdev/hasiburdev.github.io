## Why Rust?

Rust has been gaining popularity for systems programming, and for good reason. It offers memory safety without a garbage collector, making it perfect for building fast and reliable CLI tools.

## Getting Started

First, let's set up a new Rust project:

```bash
cargo new file-searcher
cd file-searcher
```

## Core Implementation

Here's the basic structure of our file searcher:

```rust
use std::fs;
use std::path::Path;

fn search_files(dir: &Path, pattern: &str) -> Vec<String> {
    let mut results = Vec::new();

    if let Ok(entries) = fs::read_dir(dir) {
        for entry in entries.flatten() {
            let path = entry.path();
            if path.is_dir() {
                results.extend(search_files(&path, pattern));
            } else if let Some(name) = path.file_name() {
                if name.to_string_lossy().contains(pattern) {
                    results.push(path.display().to_string());
                }
            }
        }
    }

    results
}

fn main() {
    let args: Vec<String> = std::env::args().collect();
    if args.len() < 3 {
        eprintln!("Usage: {} <directory> <pattern>", args[0]);
        std::process::exit(1);
    }

    let dir = Path::new(&args[1]);
    let pattern = &args[2];

    let results = search_files(dir, pattern);
    for result in results {
        println!("{}", result);
    }
}
```
