---
title: Validation and Pipes in NestJS
description: Validate input at the controller boundary with class-validator and pipes.
---

Input validation should happen before business logic runs.

## DTO + Validation Example

```ts
import { IsEmail, IsString, MinLength } from "class-validator";

export class CreateUserDto {
  @IsEmail()
  email!: string;

  @IsString()
  @MinLength(8)
  password!: string;
}
```

```ts
app.useGlobalPipes(
  new ValidationPipe({
    whitelist: true,
    forbidNonWhitelisted: true,
    transform: true,
  }),
);
```

## Best Practices

- Use DTOs for every write endpoint
- Enable `whitelist` to drop unknown fields
- Prefer explicit transformation for typed route/query params
