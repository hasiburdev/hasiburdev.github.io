---
title: Unit Testing Principles
description: Write fast, focused, and maintainable unit tests.
---

A unit test should verify one behavior with minimal dependencies.

## Core Rules

1. Arrange, Act, Assert
2. One behavior per test
3. Deterministic inputs and outputs
4. Meaningful failure messages

## Example (TypeScript)

```ts
describe("calculateDiscount", () => {
  it("applies 10% discount for premium users", () => {
    const result = calculateDiscount({ total: 200, isPremium: true });
    expect(result).toBe(180);
  });
});
```

## Common Smells

- Large test setup for simple logic
- Over-mocked tests coupled to implementation details
- Flaky assertions relying on time or randomness
