---
title: Test Doubles and Mocking
description: Use mocks, stubs, and fakes intentionally without hiding real bugs.
---

Test doubles are useful when used at clear boundaries.

## Types of Doubles

- Dummy: placeholder object not used by assertions
- Stub: returns canned responses
- Mock: verifies interactions
- Fake: lightweight working implementation

## Mocking Guideline

- Mock network, queues, and third-party APIs
- Prefer real implementations for domain logic
- Assert outcomes first, interactions second

## Example

```ts
const emailClient = { send: vi.fn().mockResolvedValue(undefined) };
await service.registerUser(input, emailClient);
expect(emailClient.send).toHaveBeenCalledWith(
  expect.objectContaining({ to: input.email }),
);
```
