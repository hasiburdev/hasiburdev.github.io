title: Integration Testing Strategy
description: Test component collaboration and real infrastructure boundaries.
---

Integration tests verify that parts of the system work together correctly.

## Good Targets

- Repository + database behavior
- Service + external adapter contracts
- Controller + middleware + serialization logic

## Practical Recommendations

- Use test containers or ephemeral databases
- Seed data explicitly per test suite
- Keep fixtures close to test intent
- Measure runtime and parallelize wisely

## Example Focus

Instead of mocking every DB call, run the repository against a real test database and assert persisted behavior.
